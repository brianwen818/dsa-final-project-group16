# snippet/ — 段落摘要、標籤與圖片

- **Stage**：3、5 之間（讓結果頁說明「為什麼相關」）
- **負責人**：温亮達（2026-11-05 完成初版）
- **期限**：11/16（Stage 5 在 11/19 前要接上）
- **依賴**：`tree/`（網站樹）、`scoring/`（關鍵字計數）、`fetch/`（Fandom API）；`engine/` 與 `semantic/` 會使用它
- **說明**：見 README 4.5「為什麼相關」與 Proposal 2.5 節

## 目標

搜尋「貓咪」時，每個結果下方列出網頁中同時和查詢詞與 OOO 相關的段落，例如：

- 中文維基「假面騎士OOO角色列表」→「卡佳里：貓系幹部，代表色是黃色…」，附卡佳里的圖片
- 中文維基「假面騎士OOO」→「獅虎豹 貓系聯組…」、「第 3 集 貓‧進化‧貪吃鬼」

## 要建立的檔案

- [x] `model/Passage.java`：段落文字、章節路徑、錨點網址、分數、標籤、圖片網址與來源
- [x] `PassageExtractor.java`：以表格列、清單項目、段落為單位切開正文；用 **Stack** 記錄章節標題路徑與錨點
- [x] `PassageRanker.java`：段落必須含查詢詞，分數 `P_q(t) = (0.1 + ln(1 + q(t))) × (1 + Σ w(k) × c(k, t))`；用 **PriorityQueue** 從整棵網站樹取前 3 段；相同內容只留一段；產生標籤（段落中的 OOO 關鍵字＋章節標題）
- [x] `ImageFinder.java`：同段落／同章節的圖片（略過小於 100px）→ 用關鍵字的英文寫法查 Kamen Rider Wiki 的 `pageimages` → Fandom 檔案搜尋；都沒有就回傳空值
- [x] 查詢詞的排除詞（例如查「貓」時排除「熊貓」「貓頭鷹」「貓熊」）：在 `data/query-synonyms.txt` 加入排除寫法的格式
- [x] 把各組合（塔托巴、獅虎豹、鍬螳蝗…）加進 `data/concepts.txt`，重新產生 `data/keywords.txt`
- [x] `cli/SearchMain` 在每個結果下方印出前 3 段、標籤與圖片網址，並輸出 `data/results/passages.csv`，用「貓咪」驗收

## 實作後的調整（2026-11-05）

- 段落入選還要「含原本的 OOO 關鍵字（權重 ≥ 2.6），或所在網頁標題提到 OOO」：擋掉從演員條目等子頁面爬到的「旅貓日記」這類段落。
- 章節圖改為最後的備用：萌娘百科「聯組形態」章節的第一張圖是鍬螳蝗，不能配給獅虎豹的段落。順序為 段落自己的圖 → 標籤查 Fandom → 章節圖。
- 跨網站去重：前面網站已顯示的段落，後面的網站不再顯示（網站樹重疊的維基條目會改顯示各自獨有的段落）。
- 0 分的網站不挑段落。

## 之後可以改進
