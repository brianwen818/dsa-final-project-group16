## 1. 今天做了什麼

專案目標確定為：**無論使用者輸入什麼關鍵字，都跳出和「該關鍵字」以及「假面騎士OOO」最相關的內容，並說明為什麼相關。** 例如搜尋「貓咪」時，要找到獅虎豹組合、貓系幹部卡佳里、第 3 集與第 13 集的貓 Yummy，而不是一般的貓咪資訊。今天依這個目標完成：

1. **查詢限定與查詢詞計分（Stage 3）**：查詢加上「假面騎士OOO」再搜尋；查詢詞加入計分，分數 = OOO 分數 × (0.1 + ln(1 + 查詢詞次數))。
2. **Stage 4 修正**：擴充詞從斷詞碎片（騎士、假面、硬幣）改善為有意義的詞，擴充後再搜尋並重新排名。
3. **正式版搜尋引擎 `RealSearchEngine`**：把 Stage 1–4 與段落摘要串成一次完整的搜尋，Stage 5 可直接呼叫。
4. **段落摘要與圖片**：每個結果附上同時提到查詢詞與 OOO 的段落、章節路徑、標籤與圖片。
5. **文件**：README 進度表與計畫、各資料夾 TODO、Stage 3/4 報告的修正紀錄；Proposal 依作業要求的 5 節重寫（22 頁 → 8 頁），重畫流程圖、類別圖與甘特圖。

## 2. 程式改動

### 新增的類別

| 檔案 | 說明 |
|---|---|
| `search/QueryScope.java` | 查詢加上主題名稱；讀取 `data/query-synonyms.txt` 的同義寫法與排除詞；查詢剛好是 OOO 關鍵字時沿用關鍵字表的寫法 |
| `search/CandidateFinder.java` | 候選網址：Google 快取用原始查詢（對照組），維基與 DuckDuckGo 用限定後的查詢；擴充後再搜尋 |
| `scoring/QueryCounter.java` | 計算查詢詞次數，略過關鍵字表與查詢詞自己的排除詞（例如「熊貓」不算「貓」） |
| `scoring/QueryAwarePageScorer.java` | 單頁分數 S_q(p) = S(p) × (0.1 + ln(1 + q(p))) |
| `tree/SiteResults.java` | 排名整理：可評分的網站在前、去除維基重新導向造成的重複網站 |
| `snippet/PassageExtractor.java` | 把網頁切成段落，用 Stack 記錄章節路徑與錨點 |
| `snippet/PassageRanker.java` | 段落計分，用 PriorityQueue 從整棵網站樹取前 3 段，產生標籤，跨網站去重 |
| `snippet/ImageFinder.java` | 段落圖片：段落自己的圖 → 用標籤的英文寫法查 Kamen Rider Wiki → 檔案搜尋 → 章節圖 |
| `model/Passage.java` | 段落資料：摘要、章節路徑、章節連結、分數、標籤、圖片與來源 |
| `engine/RealSearchEngine.java` | 正式版搜尋引擎（流程見 Proposal 3.1 節） |
| `cli/SearchMain.java` | 完整搜尋的命令列 Demo，輸出 `data/results/passages.csv` |

## 3. 執行結果

執行：`./mvnw compile exec:java -Dexec.mainClass=com.group16.ooosearch.cli.SearchMain -Dexec.args="貓咪"`（第一次需要連網，約數分鐘）

**搜尋「貓咪」**

- 前兩名是中文維基「假面騎士OOO」與「假面騎士OOO角色列表」，附上的段落包括：獅虎豹貓系聯組（配獅虎豹的圖）、LION 貓系核心硬幣被卡佳里奪走（配卡佳里的圖）、第 13 集暹羅貓 Yummy、第 3 集〈貓‧進化‧貪吃鬼〉。結果卡片見 `docs/proposal/search-cards-cat.png`。
- 擴充詞第 1 輪：外科、貪吃、進化、天才、斬碎；第 2 輪：暹罗、シャム、暹羅貓、压力、シャムネコ（都來自貓 Yummy 那兩集，不是人工提供的）。
- 再搜尋找到東映官網的第 3、13 集介紹頁（排名第 7）。

**搜尋「核心硬幣」**

- 第 1 名從原本的「角色列表」換成專講核心硬幣的 Kamen Rider Wiki「O Medals」。
