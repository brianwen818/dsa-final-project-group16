# HW1 Bonus: Prompt Log

## What this checks
This bonus looks at whether you used an AI tool to help you read and
understand code and debug, rather than just to generate your solution.

## How to submit
Add one extra file to your submission: `prompt_log.md` (or `.txt`). Copy in,
in order, every prompt you typed into the AI tool while working on this
assignment. Skip the AI's replies, just your own messages.

**Put each prompt on its own line, with a blank line between prompts.**

If you didn't use AI at all for this assignment, this bonus doesn't apply
and you won't be penalized.

## What we're looking for
Here are some of the things we might look for when we read through your
log. This isn't a strict checklist you need to satisfy item by item:

- You worked through the assignment step by step with the AI tool, rather
  than getting the whole thing from one prompt.
- You asked it to explain the problem or walk through the steps in words
  before asking for code.
- You engaged with the code it gave you, for example asking why it wrote
  something a certain way, or asking it to explain a part you didn't
  understand.
- You used it to help you debug, for example telling it what happened
  when you ran the code and working through why the result didn't match
  what you expected.

We're not grading these one by one or docking points for missing exactly
one. We're looking at your log as a whole to see if it shows you using
the tool to actually learn to read code and debug, not just prompt in,
code out, submit.
