# HW3: Count A Keyword in a Web Page!

## 作業說明

* **目標**：從使用者輸入中取得網址（URL）與關鍵字（Keyword），並計算該關鍵字在網頁內容中出現的次數。
* **加分項目（Bonus）**：實作 **Boyer-Moore 演算法**（利用 Looking-glass 與 Character-jump 啟發式規則實作 `indexOf()`）。

---

## 輸入與輸出範例 (I/O Example)

> ⚠️ **注意**：請務必嚴格核對輸出文字與標點符號，避免因格式不符遭扣分。

```text
Please type URL and Keyword: 
http://soslab.nccu.edu.tw/Welcome.html Fang
Fang appears 32 times.

```
